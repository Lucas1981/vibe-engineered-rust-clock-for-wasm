# Vibe Engineered Rust Clock for Wasm

[See hosted online](https://zzp-online-marketing.nl/rust-clock/)

So, this is a seconf iteration of the Vibe Coded Rust Clock. We learned a bit more from the previous iteration and were able to tighten the specifications and anticipate difficulties better this time. We knew that we were going to want a Wasm output.

This is also meant as a Vibe Engineered example of a complete pipeline from a Rust project to a deployed Wasm created web application. We can always come back to this and build on it, using it as a resource to set up any new projects with that are meant to be deployed as Rust -> web app. It is probably good to keep iterating on how to do that, but this can serve as a simple MVP blueprint.
